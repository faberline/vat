# vat status

## Scope

This file is the support matrix for the `vat` binary built from this tree
(`cargo build -p vat`, version in `Cargo.toml`). It records what each
user-facing surface does today, bounded by the gate that proves it. The
product direction (three pillars: Apple-native containers, complete Docker over
one shared Linux VM, realistic local GCP/GKE) is stated in
[README.md](README.md) and [ROADMAP.md](ROADMAP.md); a surface that only the
roadmap promises appears here as `Not supported` so an agent reading this file
cannot mistake intent for capability.

Hosts: Apple Silicon macOS is the primary host. Linux hosts build and run the
copy-on-write core but have no seatbelt backend. Intel macOS is untested.

## State definitions

| State | Meaning |
|---|---|
| Supported | The surface works as documented in [README.md](README.md) and a gate that `cargo test -p vat` runs (or an opt-in real-host E2E named in the row) proves it. Regressions are defects. |
| Limited | The surface works inside an explicitly bounded scope; the `Supported scope` and `Limits` cells are the contract. Behavior outside the scope fails closed rather than degrading. Legacy rows are Limited and will be superseded by a roadmap outcome before removal. |
| Not supported | The surface does not exist in this tree, or exists only as a roadmap outcome. Any apparent behavior is accidental and carries no promise. |

## Evidence policy

- A row is `Supported` only when a `cargo test -p vat` target that exists in
  `tests/` exercises it, or when the row names an opt-in real-host E2E
  (`--ignored` with its `*_E2E_REQUIRED=1` variable) that has passed on an
  Apple Silicon host with Apple Container installed.
- The `rg` gates in the matrix are documentation-presence checks carried over
  from `aw.toml`; they prove the README still states the contract, not that
  the code behaves. Every such row also names a behavior gate.
- Real-host E2E timings quoted in [README.md](README.md) are observations from
  one host, never promises. Performance budgets for the shared VM (startup,
  idle memory, file-sharing throughput) will be stated as limits in this file
  only after a measurement command exists; until then they live in
  [ROADMAP.md](ROADMAP.md) as goals.
- `Not supported` rows cite the `VAT-R-*` outcome that would change them. A
  row moves to `Limited` or `Supported` only in the same change that adds its
  gate.
- Nothing in this file binds a tracker item; tracking is assigned by the
  release process, not by this document.
